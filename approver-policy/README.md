approver-policy container
==========================

[approver-policy](https://github.com/cert-manager/approver-policy) is a cert-manager approver that governs which CertificateRequests are approved based on CertificateRequestPolicy resources. This directory provides the Dockerfile for building a container image containing approver-policy.

Docker images
-------------

Docker images are available on [ghcr.io](https://ghcr.io/cybozu/approver-policy)
